# Translations

Tripwire is in English for now. Each language goes here as one file, named by its
language code (for example `hi.json` for Hindi, `st.json` for Sesotho), and appears
on the site once it's here: a language choice shows up at the bottom of every page.

We only add a language once a native speaker has checked it. First drafts of Hindi and
Sesotho are kept on the `notes` branch (`translation-drafts/`), waiting for someone to
check them. See CONTRIBUTING.md for how to help.
