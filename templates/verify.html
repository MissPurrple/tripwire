Check a stamp of originality

Every copy kept on a Tripwire shelf comes with a stamp: where it came from, when it was taken, whether Tripwire fetched it itself or its owner uploaded it, and a fingerprint of the copy. Tripwire signs each stamp, so nobody can make or change one. Paste a stamp here (or choose the .stamp.json file) to check it. Add the copy too, to check it's exactly the one that was stamped.

Checking without Tripwire

A stamp is signed with Ed25519. The signature covers every field except signature itself, written as JSON with the keys in alphabetical order and no spaces. This Tripwire's public key is {{ public_key }} (key {{ key_id }}), and each stamp carries it too, so anyone can check the signature with standard tools, even if this site is gone. The fingerprints are SHA-256.
